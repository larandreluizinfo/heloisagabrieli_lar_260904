# Instruções do repositório

## Regra obrigatória

**Toda e qualquer alteração feita neste repositório deve ser commitada e enviada (push) para o GitHub.**

Sempre que concluir uma tarefa com alterações de arquivos:

1. Verifique as mudanças com `git status` e `git diff`.
2. Adicione os arquivos alterados com `git add`.
3. Faça o commit com uma mensagem clara e descritiva.
4. Envie com `git push` para a branch `main`.

## Extras

- Rodar `git status` antes de iniciar qualquer trabalho ajuda a não sobrescrever mudanças não commitadas.
- Nunca deixe alterações locais sem commit/push ao fim de uma sessão.
